# DriveHUD V1.10 iPhone 實機驗收清單

雲端只能用 Chromium 模擬 iPhone 15 驗證版面與邏輯；下列項目需要在 iPhone Safari 實機確認。
建議先以 GitHub Pages 預覽（合併前可在本機 `python3 -m http.server` 後用同一 Wi-Fi 的 iPhone 開啟，需 HTTPS 才能定位時請合併後再測）。

狀態欄填：✅ 通過／⚠️ 有問題（寫在備註）／— 未測。
